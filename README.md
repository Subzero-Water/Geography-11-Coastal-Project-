# Instructions for use

---

This is the GitHub repository for our Geography project.

To access this project yourself, please just run the following command in a terminal emulator of your choice (e.g. Powershell): 
```bash
git clone https://github.com/Subzero-Water/Geography-11-Coastal-Project-/tree/main
```
 Make sure your system has git installed. Please refer to the following website to download git: https://github.com/git-guides/install-git.
